# Маса по размер — konvektomat.store

Форма за поръчка на маси от неръждаема стомана (инокс) по размер.

- 3D чертеж, който се мащабира спрямо въведените размери
- няколко маси в една поръчка („Добави друга маса“), всяка със собствен чертеж
- долна основа (плот) и втори междинен плот, поставен автоматично по средата
  между основата и работния плот
- сваляне като PDF (по една маса на страница)
- изпращане на PDF-а по WhatsApp (на телефон — през менюто за споделяне;
  на компютър — PDF-ът се сваля и се отваря чатът)

Целият сайт е един файл: [`site/index.html`](site/index.html). Няма сървър и
база данни — всичко работи в браузъра на клиента.

## Публикуване

Всяко качване (push) в `main` публикува папката `site/` в GitHub Pages чрез
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml).
Адресът е `https://<потребител>.github.io/<repo>/`.

## Често променяни настройки (в `site/index.html`)

| Какво | Къде |
| --- | --- |
| WhatsApp номер | `const COMPANY_WHATSAPP = "359893457703";` (международен формат, без `+`) |
| Дебелина на ламарината (1.5 мм) | текстът „Ламарината е с дебелина“ и `tableSpec()` |
| Профил на краката (30 × 30 мм) | текстът „Профилът на краката е“, `legProfile:30` и `tableSpec()` |
| Минимално отстояние на задните крака (70 мм) | полето `f-legBack` (`min="70"`) и `Math.max(70, …)` в `readTable()` |

PDF-ът се прави с [jsPDF 2.5.1](https://github.com/parallax/jsPDF), заредена от cdnjs.
